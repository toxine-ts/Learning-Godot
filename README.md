# Godot Projects

A collection of 2D games built with Godot 4.

## Games

### Settup
A magical duel game where a Hobbit faces off against a Wizard. Hit the Wizard to shrink him while dodging his spells. Features turn-based spell combat and visual shrinking mechanics.

### Angry Bird
A physics-based puzzle game where players drag and launch animals to knock down cups across 3 levels. Features drag-and-release launching, multiple animal types, sound effects, and score tracking.

### Dice Catcher
A fast-paced arcade game where you control a fox to catch falling dice before they hit the ground. Features random dice spawning, rotation animations, score tracking, and background music.

### Foundations
An introductory project featuring plane-flying mechanics in an ocean environment. Navigate a plane with rotation and forward movement controls past obstacles like helicopters and carrier ships.

### Memory Madness
A classic memory card-matching game. Flip tiles to find matching image pairs across multiple difficulty levels with configurable grid sizes, move tracking, and a level selection system.

### Tappy
A Flappy Bird-style game where you tap to fly through moving pipes. Features physics-based gravity, randomly spawned pipes, score tracking, scrolling backgrounds, and mobile-optimized controls.
